# OPERA DIST disturbance-status classes (VEG-DIST-STATUS in DIST-ALERT-HLS,
# and the same code space in DIST-ANN-HLS).
#
# The class CODES are the product's, matching the COG's `flag_values` tag
# exactly (verified against OPERA_L3_DIST-ALERT-HLS_T05VPH_..._VEG-DIST-STATUS
# .tif, 2026-09-10). The COLOURS are ours, and deliberately NOT NASA GIBS's —
# see below. Anything reading this file to interpret a GIBS tile must map by
# class code, never by colour.
#
# WHY WE DIVERGE FROM GIBS. Their ramp paints "no disturbance" opaque near-
# black (right for a full-frame Worldview backdrop, wrong for an overlay) and
# it encodes the two axes by hue alone, which puts the enormous, mostly
# meaningless "first detection <50%" class in a saturated teal that dominates
# any view of Alaska. The two axes are:
#
#   MAGNITUDE  <50% vs >=50% of the 30 m pixel's vegetation cover lost
#   MATURITY   first detection -> provisional -> confirmed -> finished
#              (how many confirming looks the alert has had; "finished" means
#              the anomaly stopped progressing, still within the year)
#
# The scheme, Hig's call 2026-09-10, tuned for spotting EMERGING activity:
#
#   MATURITY drives hue: saturated red at first detection, dulling through
#   red-orange and sienna to a flat brown when finished. Freshest = loudest,
#   because an emerging anomaly is the thing that might still be a developing
#   hazard; an old confirmed scar is already known.
#
#   MAGNITUDE drives lightness AND saturation: >=50% is dark and saturated,
#   <50% is light and washed. The gap is WIDEST at first detection (33.6 L*,
#   vs ~29.5 for the mature classes) because "first detection <50%" is both
#   the most widespread class and the least meaningful — on one Talkeetna
#   granule the median alerted pixel had duration 1 day and a single anomalous
#   look. It has to recede on its own, without a class filter.
#
# So the eye is drawn, in order, to: fresh + big (240,51,73) first, then the
# mature large disturbances, and last if at all to the pale speculative wash.
#
# Verified with a CIE76 / Viénot-1999 CVD check (scratch script, this session):
# all 28 pairs separate by dE >= 16 in normal vision; the magnitude axis holds
# up under protanopia and deuteranopia (min dE 30) and the fresh->=50% class
# stays dE >= 15 from everything else. KNOWN LIMIT: under protanopia,
# "provisional >=50%" and "confirmed >=50%" are close (dE 7.7). Both read as
# "substantial disturbance here", so the practical cost is small — but that is
# the pair to change first if the ramp is ever retuned. The red is hue 353,
# not a pure 0: the small amount of blue is what buys the fresh class its
# separation under red-green CVD, and at hue >=356 that collapses to dE < 11.
#
# Class 0 (no disturbance) and the 255 no-data code are alpha 0. Class 0 is
# absent from the JS lookup entirely, so it and any unrecognised colour both
# fail transparent — see the comment on _distLut in map.js.
#
