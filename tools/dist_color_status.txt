# OPERA DIST disturbance-status classes (VEG-DIST-STATUS in DIST-ALERT-HLS,
# and the same code space in DIST-ANN-HLS).
#
# The class CODES are the product's, matching the COG's `flag_values` tag
# exactly (verified against OPERA_L3_DIST-ALERT-HLS_T05VPH_..._VEG-DIST-STATUS
# .tif, 2026-09-10). The COLOURS are ours, and deliberately NOT NASA GIBS's —
# see below. Anything reading this file to interpret a GIBS tile must map by
# class code, never by colour.
#
# The product crosses two axes:
#   MAGNITUDE  <50% vs >=50% of the 30 m pixel's vegetation cover lost
#   MATURITY   first detection -> provisional -> confirmed -> finished
#              (how many confirming looks the alert has had; "finished" means
#              the anomaly stopped progressing, still within the year)
#
# THE ENCODING (Hig, 2026-09-10). GIBS puts both axes on hue alone, which lets
# "first detection <50%" — the most widespread and least meaningful class —
# sit in a saturated teal that dominates any view of Alaska. Instead:
#
#   DARKNESS = IMPORTANCE, and importance is certainty x recency, with
#   saturation reinforcing it. So the darkest, most saturated class is
#   CONFIRMED (certain AND still current), not "finished": finished is just as
#   certain but its recency is gone, so it steps back to a light, dull brown.
#   Getting that wrong is easy — a plain monotonic ramp along the maturity
#   axis leaves the oldest, least actionable class the loudest thing on the
#   map. It is the mistake this ramp was rewritten to fix.
#
#   MAGNITUDE rides the same darkness channel: every <50% class is paler and
#   less saturated than its >=50% partner, by 23-34 L*. The widest gap is at
#   first detection (33.6 L*) because "first detection <50%" is both the most
#   widespread class and the least meaningful — on one Talkeetna granule the
#   median alerted pixel had duration 1 day and a single anomalous look. It
#   has to recede on its own, without a class filter.
#
#   MATURITY rides hue: saturated red when fresh, through red-orange and
#   sienna, to a flat brown when finished. First detection >=50% is therefore
#   loud through CHROMA rather than darkness — big, brand-new and unconfirmed
#   is exactly the emerging-hazard case worth a second look, without claiming
#   the certainty that would earn it a dark tone.
#
# Resulting darkness order, most important first:
#   >=50%   confirmed L*31  <  provisional L*49  <  first detection L*53  <  finished L*60
#    <50%   confirmed L*63  <  provisional L*78  <  finished L*83  <  first detection L*87
#
# ACCEPTED TRADE-OFF: eight classes will not all separate inside one red-brown
# hue family. This ramp spends its separation where it is worth something —
# min dE 25.5 within the >=50% row and 26.6 across the four magnitude pairs —
# and lets the <50% row run together at min dE 10.0. That is deliberate: the
# pale classes are background wash, and the eye should not be parsing four of
# them. They remain distinct side by side in the colour key.
#
# Colour-blind check (CIE76 + Vienot 1999, scratch script this session): the
# >=50% row and the magnitude axis hold at min dE 15.5 under both protanopia
# and deuteranopia. The red is hue 353, not a pure 0 — the small amount of
# blue is what buys the fresh class its separation under red-green CVD, and at
# hue >=356 it collapses to under dE 11.
#
# Class 0 (no disturbance) and the 255 no-data code are alpha 0. Class 0 is
# absent from the JS lookup entirely, so it and any unrecognised colour both
# fail transparent — see the comment on _distLut in map.js.
#
